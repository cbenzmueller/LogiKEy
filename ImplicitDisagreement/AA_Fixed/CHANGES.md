# Changes to the original formalization

The following corrections retain the original representations of arguments, attacks, extensions, and labellings. See [README.md](README.md#building) for build instructions and [verification scope](README.md#verification).

- **Sound relative Zorn foundations (`Zorn-lemma.thy`).** Removed the false admitted `bridge1` and `bridge2` statements. Proved the relative Zorn results by applying ordinary Zorn to predicates restricted to the argument universe, then recovering a representative. Preserved the Zorn theorem names used downstream. All proofs in this file now use native Isabelle methods, with no admissions or solver oracles.
- **Skeptical acceptance (`base.thy`).** Quantify over every semantic labelling, including labellings with an empty `In` set. The definition retains ordinary universal vacuity when no semantic labellings exist; the implication to credulous acceptance therefore has an explicit nonemptiness hypothesis.
- **Isabelle2025 compatibility and foundations (`misc.thy`, `ROOT`).** Updated hidden set notation, corrected the relative supremum/infimum characterizations, and replaced fragile foundational automation with explicit proofs. Added a session manifest. The manifest disables skipped-proof acceptance.
- **Intended experiment identifiers (`simplified/`).** Corrected the mismatched theory name, the seven converse experiments using unintended free predicates, `complete` versus `completeLab`, and lowercase `a` versus the constructor `A`. The impossible Figure 4 query is replaced by a direct proof that admissible labellings have at most two In arguments.
- **Bounded converse searches.** Three failed converse searches are specialized to the one-argument carrier `unit`, which already admits the required counterexamples. They retain the requirement for genuine counterexamples and use SAT4J with explicit unboxing.
- **Finite model generation.** Set the example argument domains to their exact sizes (four, four, and three) and the label domain to three. Removed optional cardinality display terms, whose list/natural-number encodings introduced potentially spurious models on Isabelle2025. Enumeration queries retain `findFor'` and the requirement for genuine models.
- **Ideal semantics (both correspondence developments).** Added the missing ideal extension/labelling correspondence arguments and canonical-labelling results. Replaced the simplified ideal-completeness oracle proof with an ordinary proof. Added proofs of the concrete ideal labellings in the three supplied examples. The legacy `idealOld` predicate remains explicitly marked as a deprecated counterexample definition.
- **Correct scope of existence claims (`lab-properties.thy` and its simplified counterpart).** Parenthesized the nonempty-universe premise for stable nonexistence. Added semi-stable labelling existence results for finite frameworks, without claiming unrestricted infinite existence.
- **Regression coverage (`regression-checks.thy`).** Added checks using the repaired source definitions for a self-attacking argument and an unattacked argument; added counterexamples to both removed relative/global Zorn bridges. Added a check of the full oracle ancestry of project mathematical facts. Eight exactly identified Quickcheck code-equation collections generated by Isabelle are excluded as audit roots; dependencies on them from checked mathematical facts are still rejected.

The central attack, defence, extension, and labelling interpretations are retained. Deliberately false converses and unrelated unfinished research conjectures remain visibly separated from proved results through their `oops` endings.
